# 🧩 PhishGuard AI - Chrome Extension Installation Guide

The **PhishGuard AI Chrome Extension** allows you to scan active web pages or right-click any link on the web to run real-time AI security checks.

---

## 🛠️ Step-by-Step Installation Instructions

### 1. Open Browser Extensions Page
* **Google Chrome**: Go to `chrome://extensions/`
* **Microsoft Edge**: Go to `edge://extensions/`
* **Brave Browser**: Go to `brave://extensions/`

### 2. Enable Developer Mode
Toggle the **Developer mode** switch in the **top-right corner** of the Extensions page.

### 3. Load Unpacked Extension
1. Click the **"Load unpacked"** button in the top-left.
2. Select the extension directory:
   `C:\Users\hp\.gemini\antigravity-ide\scratch\phishing-url-detection-system\extension`

---

## 🌟 How to Use

1. **Popup Scanner**: Click the **PhishGuard AI icon** in your extension toolbar while browsing any website to scan the current active page.
2. **Right-Click Context Menu**: Right-click any link on any web page and select **"Scan link with PhishGuard AI"** for instant background threat analysis!

---

> ⚠️ **Prerequisite**: Make sure your Flask server ([`app.py`](file:///C:/Users/hp/.gemini/antigravity-ide/scratch/phishing-url-detection-system/app.py)) is running on `http://localhost:5000`.
